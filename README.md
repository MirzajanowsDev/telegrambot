# Generals Access Bot v2

В меню доступны Generals Android, Counter-Strike 1.6 Android, Gemini Pro и Dota 2 на Android. У каждого товара свои цены. Generals iPhone пока скрыт. Поддерживаемые товары:

- 🎯 Counter-Strike 1.6 Android
- 🎮 Generals Android
- 🤖 Gemini Pro
- ⚔️ Dota 2 на Android

И 3 варианта оплаты на каждый товар:

- 🇷🇺 Россия — ₽
- 🇺🇿 Узбекистан — сум
- 🇰🇬 Кыргызстан — сом

RU и KG реквизиты общие для всех товаров. UZ реквизиты — отдельная карта на Generals (Android/iPhone) и отдельная на Gemini Pro.

## Настройка

Скопируйте `.env.example` в `.env` и заполните:

```env
BOT_TOKEN=...
ADMIN_ID=...
CHANNEL_ID=-100...
DEFAULT_SUPPORT_USERNAME=mirzajonows

PAYMENT_RU=ваши российские реквизиты
PAYMENT_KG=ваши кыргызские реквизиты

PAYMENT_UZ_ANDROID=узбекские реквизиты для Generals
PAYMENT_UZ_GEMINI=узбекские реквизиты для Gemini Pro
```

Цены уже выставлены (можно менять):

```env
PRICE_ANDROID_RU=500 ₽
PRICE_ANDROID_UZ=50 000 сум
PRICE_ANDROID_KG=500 сом

PRICE_IPHONE_RU=1000 ₽
PRICE_IPHONE_UZ=80 000 сум
PRICE_IPHONE_KG=700 сом

PRICE_GEMINI_RU=500 ₽
PRICE_GEMINI_UZ=50 000 сум
PRICE_GEMINI_KG=500 сом
```

## Запуск

```bash
npm install
npm start
```

## Как работает

1. Пользователь выбирает язык.
2. Выбирает товар: Generals Android / Counter-Strike 1.6 Android / Gemini Pro / Dota 2 на Android.
3. Нажимает «Оплатить доступ».
4. Выбирает страну оплаты — суммы и реквизиты подставляются для выбранного товара.
5. Бот показывает соответствующие реквизиты.
6. Пользователь отправляет чек.
7. Вам приходит чек с указанием товара, страны и суммы.
8. Вы нажимаете «✅ Подтвердить» или «❌ Отклонить».
9. Для Generals, CS 1.6 и Dota 2 бот создаёт одноразовую ссылку в соответствующий закрытый канал. Для Gemini Pro бот подтверждает оплату и сообщает, что `@mirzajonows` отправит ссылку активации в течение 30 минут.

После выбора языка постоянная клавиатура под полем ввода содержит две локализованные кнопки на отдельных строках: «🛒 Меню товаров» / «🛒 Mahsulotlar» и «🌐 Изменить язык» / «🌐 Tilni o'zgartirish». Кнопки «🇷🇺 Русский» и «🇺🇿 O'zbekcha» появляются только после `/start` или нажатия кнопки смены языка. Сообщение с выбором языка удаляется после выбора.

## Counter-Strike 1.6 Android

Канал и цены уже настроены по умолчанию. При необходимости их можно переопределить в `.env`:

```env
CHANNEL_CS16_ID=-1004335642053
PRICE_CS16_RU=700 ₽
PRICE_CS16_UZ=50 000 сум
PRICE_CS16_KG=500 сом
```

Добавьте бота администратором этого канала с правом приглашать пользователей.
RU/KG реквизиты общие. Для UZ используются `PAYMENT_UZ_ANDROID`; при необходимости задайте отдельные в `PAYMENT_UZ_CS16`.
После изменения `.env` перезапустите бота.

После подтверждения чека администратором покупатель CS 1.6 получает одноразовую ссылку в `CHANNEL_CS16_ID`. Generals использует `CHANNEL_ID`. Канал определяется по товару в чеке, даже если покупатель затем выбрал другой товар.

## Dota 2 на Android

По информации владельца, товар — нативная Android-игра на Unity, поставляемая как APK и запускаемая без эмулятора, а не стриминг с ПК. Сам APK не предоставлен для проверки: происхождение, совместимость и работоспособность независимо не подтверждены. Название товара не означает официальный порт Valve. В коде нет APK или ссылок на скачивание; реальные материалы владелец размещает в своём канале.

Карточка и описание доступны на русском и узбекском. Цены по указанию владельца: 1000 ₽, 80 000 сум, 600 сом. Канал владельца `-1004334193236` используется по умолчанию. Добавьте бота его администратором с правом приглашать пользователей. При необходимости переопределите настройки:

```env
CHANNEL_DOTA2_ID=-1004334193236
PRICE_DOTA2_RU=1000 ₽
PRICE_DOTA2_UZ=80 000 сум
PRICE_DOTA2_KG=600 сом
PAYMENT_UZ_DOTA2=
```

`CHANNEL_DOTA2_ID` должен иметь вид `-100…`; значение не подставляется из каналов других товаров. Явно пустое или некорректное значение отключает оплату, приём чека, повторную отправку и подтверждение выдачи, включая старые кнопки; карточка остаётся видимой. RU/KG реквизиты общие; `PAYMENT_UZ_DOTA2` необязателен и использует `PAYMENT_UZ_ANDROID`, если не задан. После изменения настроек перезапустите бота.

Покупатель выбирает валюту, отправляет фото/PDF чека, администратор подтверждает или отклоняет оплату. После подтверждения бот создаёт одноразовую ссылку именно в `CHANNEL_DOTA2_ID`, используя товар из сохранённого платежа. Статус и повторная отправка отклонённого чека работают как у других товаров.

## Gemini Pro

Gemini Pro не использует закрытый канал. При выборе товара бот показывает состав пакета сроком до 18 месяцев: Gemini Pro, Google One, Nano Banana, 5 TB Google Drive, Antigravity и Flow. После подтверждения оплаты бот сообщает, что `@mirzajonows` отправит ссылку активации в течение 30 минут. Пользователь должен быть онлайн, включить запись экрана до открытия ссылки и записать процесс активации. Кнопка поддержки для всех продуктов ведёт к `@mirzajonows`.

## Хранение данных на Railway

Бот хранит пользователей и оплаты в JSON-файле. Чтобы данные не сбрасывались после нового деплоя, подключите Railway Volume и задайте путь к файлу через переменную:

```env
DATA_PATH=/путь-к-volume/data.json
```

Точный путь возьмите из настроек подключённого Railway Volume. Без volume история пользователей и оплат может потеряться при пересоздании контейнера.

Рабочий `data.json` содержит персональные данные и не должен попадать в Git. Для локального запуска можно скопировать `data.example.json` в `data.json`; бот также создаст новый файл автоматически при первом сохранении.

Для реквизитов можно использовать формат `номер|подпись`, например `8600 1234 5678 9012|Имя Владельца`. Бот также распознаёт существующий формат с пробелом между номером и подписью.
