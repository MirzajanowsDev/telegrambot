# Generals Access Bot v2

Теперь в боте 3 варианта оплаты:

- 🇷🇺 Россия — 500 ₽
- 🇺🇿 Узбекистан — 50 000 сум
- 🇰🇬 Кыргызстан — 500 сом

Каждый вариант имеет отдельные реквизиты в `.env`.

## Настройка

Скопируйте `.env.example` в `.env` и заполните:

```env
BOT_TOKEN=...
ADMIN_ID=...
CHANNEL_ID=-100...

PAYMENT_RU=ваши российские реквизиты
PAYMENT_UZ=ваши узбекские реквизиты
PAYMENT_KG=ваши кыргызские реквизиты
```

Цены уже выставлены:

```env
PRICE_RU=500 ₽
PRICE_UZ=50 000 сум
PRICE_KG=500 сом
```

## Запуск

```bash
npm install
npm start
```

## Как работает

1. Пользователь выбирает язык.
2. Нажимает «Оплатить доступ».
3. Выбирает:
   - Россия — 500 ₽
   - Узбекистан — 50 000 сум
   - Кыргызстан — 500 сом
4. Бот показывает соответствующие реквизиты.
5. Пользователь отправляет чек.
6. Вам приходит чек с указанием страны и суммы.
7. Вы нажимаете «✅ Подтвердить» или «❌ Отклонить».
8. При подтверждении бот сам создаёт одноразовую ссылку в закрытый канал.
